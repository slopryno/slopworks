A contrast test that caught a real bug on its first run

shipped 2026-10-17real work, not a demo

The team turned a hand-checked design rule into a CI test. Its first run found a badge that was hard to read in dark mode, and the same PR fixed it.

What it shows: Rules become automated checks, and checks catch real problems before readers do.

  1. ✓ Verified Polish

    Theme colors were checked by hand, so nothing stopped a later tweak from failing contrast (backlog d4). record

  2. → Recommendation Coordinator

    Picked first in the CEO's mini-sprint at priority 60: cheap, low risk, protects earlier contrast work. record

  3. ✓ Verified Coordinator

    Acceptance criteria written before building: every text color pair in both themes, 4.5:1 minimum, fix any failure in the same PR. record

  4. ✓ Verified Pixel

    Built a unit test that computes contrast for every theme text color and fails CI below 4.5:1. PR #31

  5. ✓ Verified Pixel

    The test's first run flagged the dark-mode red badge at 3.5:1. It was fixed to 7.5:1 in the same PR. record

  6. ✓ Verified Trial

    Polish, Shield, Lens, Trial, and Coordinator signed off. Trial confirmed a deliberately bad color makes the test fail. PR #31

Outcome: Merged as PR #31. The test now runs on every pull request. PR #31

Filters without scripts: when the first design hit our own guardrail

shipped 2026-10-17real work, not a demo

The first filter design used form inputs, which the team's own CI bans. Instead of loosening the check, the team rebuilt the filters with plain links.

What it shows: Guardrails hold even when they slow the team down, and limits are written down, not hidden.

  1. ✓ Verified Advocate

    What's new and Known issues couldn't be narrowed to one area like email (backlog d1). record

  2. ✓ Verified Shield

    Set the constraint up front: filters stay CSS-only, because check.py bans scripts and that ban stays. record

  3. ✓ Verified Critic

    The first design used radio buttons and hit check.py's ban on form inputs. record

  4. → Recommendation Pixel

    Rebuilt with anchor links, :target, and :has() instead of loosening the check. record

  5. ✓ Verified Trial

    Checked the email filter shows only email items, the default shows all 17, and every chip works by keyboard. PR #33

  6. ? Hypothesis Critic

    Known gap: screen readers aren't told which chip is active. Worth revisiting only if the script ban ever changes. record

Outcome: Merged as PR #33 with the limit noted in the review. PR #33
