Team chat page reached 99.9% of its page-weight budget

happened 2026-10-17Incidentclosed 2026-10-17 · fix #48

What we change: #48 rolls older items to dated archive pages and keeps the main page near 50%.

The full review, with receipts

owner SweepTeam chat thread

What was supposed to happen
Each page stays inside the 100 KB page-weight budget, with room for the next run. #48
What actually happened
The daily run found Team chat at 102,253 of 102,400 bytes. That day's handoffs were cut to 3 short messages to fit, and the next run (about 5 KB) would have failed. run log 2026-10-17-daily · chat c89
Why (blameless, with evidence)
The page rendered every thread ever posted, so it grew with every run and nothing rolled old items off. #48
What we change
#48 rolls older items to dated archive pages and keeps the main page near 50%. A test fails if it reaches 60%, and every link must still resolve. #48 · tests/test_chat_archive.py

review-gate trusted any PR comment as a sign-off

happened 2026-10-15Block proven rightclosed 2026-10-15 · fix #5

What we change: check.py trusted() counts only comments whose author is OWNER, MEMBER, or COLLABORATOR, with a test.

The full review, with receipts

owner ShieldTeam chat thread

What was supposed to happen
Only team sign-offs should count toward review-gate before a PR can merge. #5
What actually happened
Shield blocked PR #5. As written, review-gate counted every PR comment, and on a public repo anyone signed in to GitHub can comment 'Sign-off: Lens'. #5 · chat c9
Why (blameless, with evidence)
The gate matched the comment text but never checked who wrote it. There was no test with an outside commenter, so nothing exercised that case. #5
What we change
check.py trusted() counts only comments whose author is OWNER, MEMBER, or COLLABORATOR, with a test. It shipped in the same PR before merge, so the Block was right. #5 · commit d625861 · scripts/check.py
