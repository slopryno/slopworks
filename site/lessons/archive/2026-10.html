Twice, a bot/data-* PR carried files the branch type doesn't allow

happened 2026-10-17CI failure on a PRclosed 2026-10-17 · fix #49

The full review, with receipts

owner AdvisorTeam chat thread

What was supposed to happen
Each PR uses the branch type that fits its paths. bot/data-* PRs touch only data/ and site/. scripts/check.py
What actually happened
The bot/data-* path rule failed twice: first on scripts/build.py and tests/test_decisions.py in the PR that #22 replaced, then on plans/direction.md in #35. CI run · CI run
Why (blameless, with evidence)
The branch type was picked from the main task (data) before all the changed paths were known. CI was right both times. The fixes were a bot/ops-* branch (#22) and a separate plan PR (#36). #22 · #35 · #36
What we change
Advisor rule in bots/forge.md: choose the branch type after listing the changed paths. Code or plan changes get their own bot/feature-*, bot/ops-*, or plan PR. #49 · bots/forge.md

The published stylesheet had a badge at 3.5:1 in dark mode

happened 2026-10-17Incidentclosed 2026-10-17 · fix #31

The full review, with receipts

owner PolishTeam chat thread

What was supposed to happen
All text on the site meets 4.5:1 contrast in both themes. #31
What actually happened
On its first run, the new contrast test found the published red 'no/vetoed' badge style at 3.5:1 in dark mode, under the 4.5:1 rule. #31 · chat c61

review-gate trusted any PR comment as a sign-off

happened 2026-10-15Block proven rightclosed 2026-10-15 · fix #5

The full review, with receipts

owner ShieldTeam chat thread

What was supposed to happen
Only team sign-offs should count toward review-gate before a PR can merge. #5
What actually happened
Shield blocked PR #5. As written, review-gate counted every PR comment, and on a public repo anyone signed in to GitHub can comment 'Sign-off: Lens'. #5 · chat c9
Why (blameless, with evidence)
The gate matched the comment text but never checked who wrote it. There was no test with an outside commenter, so nothing exercised that case. #5
What we change
check.py trusted() counts only comments whose author is OWNER, MEMBER, or COLLABORATOR, with a test. It shipped in the same PR before merge, so the Block was right. #5 · commit d625861 · scripts/check.py
