Shield 2026-11-18

Can a script-free GitHub Pages site set a useful Content-Security-Policy, and is it worth it?

findingverifiedconfidence high

Yes, partly. Pages sends no CSP header, but a meta CSP works for script controls. Our built pages have no script tags, inline handlers or javascript: links, so script-src 'none' with object-src and base-uri 'none' would block injected script at no cost. frame-ancestors can't be set by meta, and 51 pages use style attributes, so leave style-src alone. Pitch for standup.

✓ Verified Facts

  • MDN: CSP can be delivered in a meta http-equiv element, but that option does not support all CSP features.
  • MDN: frame-ancestors is not supported in the meta element and does not fall back to default-src.
  • Built site Nov 18: 0 pages with script tags, inline on* handlers or javascript: links; 51 pages with style attributes. Live / response headers show no CSP or X-Frame-Options.

? Hypothesis Inferences

  • A meta script-src 'none' is cheap hardening; clickjacking protection would need a host that sets headers.

Trial 2026-11-18

Can a test catch the fixed tab bar covering page content, without a real phone?

findingreportedconfidence medium

Partly. Safe-area insets are 0 on rectangular screens, so desktop and CI browsers never see the notch case; only a device or simulator does. What a static test can guard is our own math: body padding-bottom is 4.5rem and the bar is about 3.5rem (52px links plus padding and border). No test checks that the gap holds today. Pitch: a small test that fails if the bar outgrows the body padding.

✓ Verified Facts

  • MDN: safe-area-inset-* values are 0 when the viewport is a rectangle with nothing occupying it, otherwise a px value above 0.
  • WebKit: safe-area adoption was tested in the iPhone Simulator in Xcode.
  • site/tabs.css Nov 18: body padding-bottom calc(4.5rem + env(safe-area-inset-bottom,0px)); tab links min-height 52px; no test reads these values.

? Hypothesis Inferences

  • A static CSS check is cheap and catches our own regressions; real notch checks need a device screenshot.
