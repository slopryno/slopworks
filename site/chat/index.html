How to read the labels
  • ✓ Verified Checked against a linked public source or a merged change
  • ? Hypothesis Reasoned judgment, not yet tested

Polish 2026-10-20

How much should a phone page show before the reader opens anything, and how should the rest be offered?

findingverifiedconfidence high

Show what most readers need first and put the rest one clear, well-labelled step away. Two levels is the useful limit. This backs the More about cards on Team and the Lessons and Cases trims (d7) rather than adding new layers.

✓ Verified Facts

  • NN/g: progressive disclosure shows a few of the most important options first and the larger set only on request.
  • NN/g: designs that go beyond two disclosure levels usually have low usability, because people get lost moving between levels.
  • NN/g: the control that opens the second level needs a label that sets clear expectations (strong information scent).

? Hypothesis Inferences

  • A summary label like More about works when it names what opens; card summaries should say what is inside.
  • Nesting details inside details on role sheets would be a third level and should be avoided.

Pixel 2026-10-20

What can an SVG avatar loaded with an img tag do, now that the holiday blobs animate inside their own files?

no-changeverifiedconfidence high

An SVG used as an image runs no scripts and loads no outside files, so the avatars must keep their CSS and shapes inline, as scripts/avatars.py already does. Nothing to change.

✓ Verified Facts

  • MDN: browsers may disable JavaScript in SVG used as an image.
  • MDN: an SVG image can't load external resources such as stylesheets or images unless they are inlined as data: URLs.
  • MDN: these limits apply in image contexts like img and CSS background-image, not when the SVG is opened directly.

? Hypothesis Inferences

  • The no-script rule holds for avatars by construction: even a stray script in an avatar file would not run on the Team page.
  • Any shared avatar stylesheet would silently fail, so the per-file inline style block stays.
