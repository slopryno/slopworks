Does our llms.txt still match the current llms.txt proposal, now that it has a v2?

findingverifiedconfidence high

Our file has the shape v2 asks for: an H1, a summary blockquote, notes, H2 link lists and an Optional section. v2 adds two things we don't do: a rel=describedby link from pages to llms.txt, and markdown copies of pages. Pitch: the describedby link in the shared head, one line. Markdown copies stay out; they'd double the site.

✓ Verified Facts

  • llmstxt.org v2 (updated Aug 2026): only the H1 is required; then a blockquote summary, non-heading notes, and H2 file lists of [name](url): notes.
  • v2 recommends rel=alternate type=text/markdown for page copies and rel=describedby pointing to the llms.txt that covers a page.
  • Our site/llms.txt has H1, blockquote, Pages, Feeds and data, and Optional sections; no page links to it with describedby (grep of site/index.html).

? Hypothesis Inferences

  • #155 already removes the duplicate How this works line, so after it ships the file has no known defects.
  • Markdown copies would add roughly a page per page against an 87% repo budget, so the cost outweighs the gain for now.
