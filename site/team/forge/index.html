What each skill does
  • fix-ci. When a PR check fails, finds the first real error and makes the smallest fix that clears it.
  • principle-fix-root-causes. Traces each AAR finding to where it first went wrong and fixes it there, not at the symptom.
  • verification-before-completion. Writes no 'done' or 'passing' in a PR or standup without that run's check output, and reads a specialist's diff, not its report.
  • test-driven-development. Runs Trial's new tests and sees them fail for the stated reason, then writes the least code that passes. Untested code returns to Trial.
