What each skill does
  • architect. Sketches the data files and their shape before code, so Trial can write tests against the plan.
  • sharpen. States what Ryno is really asking for, and how much detail the plan needs, before planning starts.
  • brainstorming. Before a plan, plays Ryno's ask back in short parts, marks guesses as guesses, sizes the work and asks only what changes the build.
  • writing-plans. Splits each plan into tasks small enough for one test cycle and one review, each step with a result Trial can check.
