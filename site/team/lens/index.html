What each skill does
  • make-pr-easy-to-review. Asks for a summary that matches the diff, with core files apart from rebuilt pages, before review starts.
  • control-ui. Opens built pages in the box browser to confirm each fact and number shows as the data says.
  • get-pr-comments. Before a second review round, lists every open comment so nothing is missed under the two-round cap.
  • requesting-code-review. Reviews each PR against its base, head and plan, and sorts findings as Critical, Important or Minor. Only the first two block.
