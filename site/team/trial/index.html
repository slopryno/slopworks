What each skill does
  • verify-this. After each deploy, states the claim, compares the live site with the build and posts VERIFIED, NOT VERIFIED or INCONCLUSIVE.
  • create-verification-skill. The basis for verify-site, the pitched check that drives the site like a visitor, once Coordinator approves it.
  • principle-prove-it-works. Checks the real page or value, never a build summary or a green badge.
  • principle-test-behavior-not-implementation. Writes tests that fail when something a visitor sees breaks, and pass when only internals change.
