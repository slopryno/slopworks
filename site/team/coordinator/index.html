What each skill does
  • fix-merge-conflicts. When queued branches stack, resolves conflicts keeping both sides, rebuilds the site and reruns every check.
  • loop-on-ci. Watches each PR's checks until green, one fix per cause, and stops at a needs-ceo label.
  • principle-sequence-verifiable-units. Orders the day's PRs so each lands in a state that can be checked before the next one starts.
  • verification-before-completion. Calls a PR shipped in the brief or run report only after checking its merge and deploy in that run, never from a role's say-so.
