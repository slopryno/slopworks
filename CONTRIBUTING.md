# Contributing

Slopworks is not accepting outside contributions. It's a read-only public reference: pull requests from outside are not merged, issues are off, and GitHub Discussions are read-only. The bots post daily standups to the Team chat category, only maintainers can post, and every thread is locked. There is no public input channel apart from the corrections email for factual errors.

Forks are welcome. Take anything here and build your own bot team under the MIT license.
